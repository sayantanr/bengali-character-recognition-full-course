# 🌟 Overview

This repository accompanies a comprehensive research investigation into Bengali handwritten character recognition, exploring the complete evolution of recognition systems from classical machine learning algorithms to modern deep learning architectures and hybrid CNN–Transformer frameworks.

The project was designed to answer a fundamental research question:

> How do traditional machine learning algorithms compare with lightweight convolutional neural networks, residual hybrid CNN architectures, AutoML pipelines, and large-scale CNN–Transformer fusion models when evaluated on the same Bengali handwritten character recognition problem?

To address this question, multiple families of models were systematically designed, trained, evaluated, and compared under a unified experimental framework.

The resulting study represents one of the most extensive comparative investigations of Bengali handwritten character recognition, spanning:

* Classical Machine Learning
* Automated Machine Learning (AutoML)
* Feature Engineering
* Principal Component Analysis (PCA)
* Lightweight Deep Learning
* Residual Convolutional Networks
* CNN–Transformer Fusion Architectures
* Edge-AI-Oriented OCR Systems

---

# 🎯 Research Objectives

The primary objectives of this research are:

* Investigate the effectiveness of classical machine learning algorithms for Bengali OCR.
* Evaluate the impact of feature engineering and dimensionality reduction.
* Develop lightweight CNN architectures suitable for resource-constrained environments.
* Design hybrid deep learning systems capable of achieving state-of-the-art performance.
* Analyze the trade-offs between model complexity and recognition accuracy.
* Establish reproducible benchmarks for future Bengali OCR research.

---

# 📚 Research Motivation

Handwritten Bengali character recognition remains a challenging problem due to:

* Large intra-class variability
* Diverse handwriting styles
* Complex character morphology
* Similar-looking character classes
* Limited publicly available benchmark studies

Although deep learning has dramatically improved OCR performance, a comprehensive comparison between traditional machine learning methods and modern deep learning architectures remains scarce.

This project bridges that gap by evaluating multiple generations of recognition systems within a single experimental framework.

# 🗂 Dataset Characteristics

The experiments were conducted on a Bengali handwritten character dataset containing:

| Property        | Value  |
| --------------- | ------ |
| Total Classes   | 50     |
| Training Images | 12,000 |
| Testing Images  | 3,000  |
| Total Images    | 15,000 |

The dataset provides a balanced evaluation environment for assessing classifier performance across multiple recognition paradigms.

The study evaluates a diverse collection of machine learning algorithms, including:

* K-Nearest Neighbors
* Logistic Regression
* Random Forests
* Decision Trees
* Extra Trees
* Ridge Classifiers
* SGD Classifiers

* Passive Aggressive Classifiers

These models establish strong baseline benchmarks for Bengali OCR.

---

## AutoML and Feature Engineering

A dedicated feature-engineering pipeline was constructed to evaluate the impact of dimensionality reduction and automated model selection.

The pipeline incorporates:

* Feature normalization
* Principal Component Analysis
* Automated classifier benchmarking
* Performance comparison across multiple learning algorithms

The feature space was reduced while preserving the majority of the original information content, enabling efficient experimentation across numerous classifiers.

---

# ⚡ Super-Charged LeNet

The Super-Charged LeNet architecture was developed as a lightweight yet highly effective deep learning model.

Key design goals included:

* Low parameter count
* Fast training
* High recognition accuracy
* Edge-device compatibility
* Mobile deployment feasibility

Despite its compact design, the model achieved remarkable recognition performance and demonstrated that carefully optimized CNN architectures remain highly competitive.

---

# 🔥 Fast14M Residual LeNet-Style Hybrid CNN

The Fast14M architecture represents the highest-performing model developed during this research.

The network combines:

* LeNet-inspired feature extraction
* Residual learning mechanisms
* Deep hierarchical representation learning
* Feature mixing strategies
* Modern optimization techniques

This architecture achieved the strongest recognition performance among all evaluated systems and demonstrates the effectiveness of task-specific hybrid CNN design.

---

# 🌐 CNN–Transformer Fusion Architecture

To investigate the potential of large-scale hybrid architectures, a multi-backbone fusion framework was developed.

The framework integrates:

* LeNet
* ResNet
* VGG
* EfficientNet
* Vision Transformer (ViT)

The objective was to combine:

* Local feature extraction
* Hierarchical visual representations
* Global contextual modeling
* Attention-based learning

into a unified recognition system.

# 📈 Major Research Findings

Several important conclusions emerged from the experiments.

## Deep Learning Dominates Classical Machine Learning

Modern CNN architectures substantially outperformed traditional machine learning methods across all evaluation metrics.

---

## Bigger Is Not Always Better

The largest architecture was not the strongest performer.

The experiments revealed that architectural efficiency and task-specific design are often more important than simply increasing model complexity.

---

## Lightweight Models Remain Extremely Competitive

The Super-Charged LeNet demonstrated that compact architectures can achieve excellent recognition performance while maintaining deployment efficiency.

This finding is particularly relevant for:

* Mobile AI
* Edge Computing
* Embedded Systems
* Real-Time OCR Applications

---

## Hybrid CNN Architectures Remain Highly Effective

The Fast14M Residual LeNet-Style Hybrid CNN achieved the strongest overall performance, demonstrating the continued relevance of optimized convolutional architectures even in the Transformer era.
